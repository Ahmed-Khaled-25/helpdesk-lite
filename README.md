# HelpDesk Lite

Frontend-only HelpDesk demo for small teams.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage

## Demo IDs
- E001 / E002 — Employee
- S001 / S002 — Support
- M001 — Manager

## Render
Deploy as a **Static Site**. Branch: `main`. Build Command: empty. Publish Directory: `.`

## Limitation
localStorage is browser-specific, so data is not shared between different browsers/devices.
